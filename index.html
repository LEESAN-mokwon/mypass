내 방식 패스: 키오스크가 나에게 맞춰집니다

휴대폰에서 약 30초 진단으로 ‘내 방식’(큰 글씨, 쉬운 말, 소리 안내, 말로 주문, 시간 제한 없음 등)을 만들고, QR을 키오스크에 보여주면 화면이 그 방식으로 바로 바뀝니다. 말로 하는 주문은 직접 학습시킨 AI가 브라우저 안에서 알아듣습니다.

카페 주문기는 ‘내 방식’에 맞춰 처음부터 설계한 화면입니다(말로 주문 포함).

※ ‘기본 화면’은 실제 키오스크에서 흔한 불편(작은 글씨, 영어 메뉴, 시간 제한, 품절 칸, 많은 옵션)을 일부러 재현한 것입니다.

AI가 알아듣는 과정 보기

키오스크의 ‘말로 주문’에 쓰이는 모델입니다. 문장을 넣으면 무엇을 원하는지(의도)와 메뉴·수량·온도를 뽑아냅니다. 문장 이해는 인터넷 서버로 보내지 않고 이 브라우저 안에서 계산합니다. (음성→글자 변환은 브라우저 음성인식 기능을 쓰며, 크롬에서는 이 단계가 구글 서버를 거칩니다. 실제 키오스크에서는 기기 안 음성인식으로 바꿀 수 있습니다.)

망설임 감지 (기본 화면에서 작동)

멈춰 있는 시간, 버튼 옆을 잘못 누른 횟수, 뒤로·닫기 반복, 남은 시간을 합쳐 점수를 냅니다. 1을 넘으면 키오스크가 먼저 도움을 제안합니다.

망설임 지수0.00
모델글자 1~3그램 해시 특징(4,096차원) + 다항 로지스틱 회귀, 9가지 의도 학습카페 주문 문장 14,000개(조합 생성 + 음성인식 오류 흉내)로 직접 학습 메뉴 찾기정확 일치 → 자모 단위 유사도(‘아메리카로’, ‘까페라떼’ 같은 오인식 허용) 평가학습 문장과 겹치지 않는 문장만 셈 · 모델 고정 후 새로 쓴 50문장(사투리 포함): 의도 98.0%, 의도·메뉴·수량·온도 완전 일치 92.0% · 음성인식 오류를 섞은 합성 965문장: 의도 99.6%, 완전 일치 90.6% 되묻기메뉴를 못 찾으면 소리가 가장 비슷한 메뉴로 “혹시 ○○ 말씀이세요?”라고 되묻습니다 범용 연동웹 화면 키오스크는 연동 도구(SDK)를 붙여 화면 코드 수정 없이 글씨·버튼·쉬운 말·소리·시간을 바꿉니다 (민원발급기 탭, 시연용 모형) 망설임 감지현재는 행동 신호를 합친 규칙 기반 점수이며, 실제 사용 기록이 쌓이면 학습 모델로 바꿀 계획입니다

시험 기록 (같은 주문, 두 화면 비교)

과제 예: “따뜻한 유자차 두 잔을 주문하세요.” 기본 화면과 내 방식 화면에서 각각 해 보면 걸린 시간과 터치 수가 자동으로 기록됩니다. 가족·지인과 해 보고 결과를 복사해 두세요.

이 페이지는 공모전 제출용 시제품입니다. 메뉴의 ‘쉬운 말’과 영어·베트남어·중국어 표기는 생성형 AI로 만든 뒤 사람이 검수한 문장이며, 실제 매장에서는 메뉴를 등록할 때 한 번 변환해 둡니다. 소리 안내와 음성 인식은 브라우저 기능(크롬 권장)을 씁니다(크롬 음성 인식은 구글 서버를 거침). QR에는 이름이나 장애 여부 같은 개인정보 없이 ‘필요한 방식’만 들어 있고, 키오스크는 주문이 끝나면 이를 지웁니다.
